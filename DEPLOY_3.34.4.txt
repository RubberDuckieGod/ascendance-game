ASCENDANCE 3.34.4 — EMBEDDED WORLD MAP HOTFIX

WHY THIS BUILD EXISTS
3.34.3 could render the fantasy UI while the separate map PNG failed to load on deployment, leaving a dark canvas with clickable region polygons.

FIX
The high-fantasy world map is now embedded directly inside public/world-map-3344.js as WebP data. No separate map image upload is required for the browser map to display.

UPLOAD / REPLACE
1. public/index.html
2. public/world-map-3344.js

KEEP
- public/world-map-3342.js
- public/world-map-3343.js
- all existing campaign/narrative scripts

OPTIONAL
public/assets/ascendance-world-map-3344.webp is included for inspection/future use, but 3.34.4 does not depend on it.

AFTER UPLOAD
Restart the service if your host requires it, then hard refresh with Ctrl+Shift+R. The version should show v3.34.4.
