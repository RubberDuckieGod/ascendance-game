# Ascendance 3.25.5 — Playtest Fixes

Built from 3.25.4 after a four-player Q001 playtest.

Key fixes:
- Expanded-Hero decks repair if empty as well as if contaminated by another Hero; fixes Elara drawing no opening deck in four-player games.
- Search and Encounter Resolve buttons are rebound to the final workbook-backed controllers (the earlier UI binding pointed at superseded prototype functions).
- Encounter rewards use the Hero who triggered the encounter.
- Search cancel refunds the correct Hero, including H003–H010.
- SD063 Distant War Horn applies +1 Severity.
- SD080 Lost Merchant opens Common merchant access with the printed 10 Gold discount.
- SD021 Old Ranger Signal grants one free connected Explore/reveal through the existing placement engine.
- SD059 Stinging Swarm prevents Health recovery through the end of the Hero turn.
- Merchant Caravan provides merchant access while clear of enemies.
- Mira Precision Bolt gains +1 Attack against a target with a Status.
- Aldric Rally supports the full ten-Hero roster.
- Iron Longsword Parry is automatic once per round on a melee hit and costs no Action.
- Adventure Log remains at the newest entries at the top rather than auto-scrolling to the bottom.
- Completed Quest status is preserved; Q001 no longer flips back to Available after completion.
