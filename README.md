# Ascendance 3.32.2

Server-phase and campaign-authority consolidation built from 3.31.2. The room now owns phase transactions and randomness, persistent Hero rejoin claims/campaign metadata, and the canonical state ledgers; direct whole-game `STATE` writes are retired in favor of compatibility patches that cannot overwrite authoritative domains.

Completed Quests still allow normal continued adventuring under the full rules until **Proceed to Downtime**.

See `README_3.32.2.txt` for implementation details, architecture notes, and verification results.
