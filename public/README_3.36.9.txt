Ascendance 3.36.9 — iPhone Search + Encounter Resolution

Fixes the mobile resolution gap left after 3.36.7/3.36.8 replaced the desktop left rail on phones.

IPHONE SEARCH
- Tap Search -> the eligible Search card opens automatically in a dedicated full-screen reader.
- Shows card name, eligibility, full effect text, and skipped-card note.
- Resolve Search Card invokes the existing authoritative Search resolver.
- Cancel Search invokes the existing cancellation/refund path.
- View Map closes the full-screen card without losing the pending Search.
- A persistent "Return to Search Card" button remains until the Search is resolved/cancelled.

IPHONE ENCOUNTERS
- If Search (or Travel) starts an Encounter, the Encounter automatically opens in its own full-screen mobile view.
- Shows Encounter name, severity, and full effect.
- View Map preserves the pending Encounter and leaves a "Return to Encounter" button.
- Resolve Encounter uses the existing Encounter resolver.

No Search/Encounter game rules were changed. This is mobile presentation/control parity.
Custom Hero Creator remains excluded.
